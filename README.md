An der Schnittstelle von **Intensivpflege, Pädagogik und Medienwissenschaft.** Hier entstehen datenschutzfreundliche, offen lizenzierte Werkzeuge u.a. für die Lehre — aus dem Alltag heraus.

Ich bin Lehrer für Pflegeberufe und komme aus der Intensivpflege. Was hier liegt, ist im Unterricht entstanden: weil eine Übung fehlte, eine Planung zu lange dauerte oder ein Begriff immer wieder erklärt werden musste.

→ **[florianloyns.com](https://florianloyns.com/)** — alle Werkzeuge auf einen Blick

---

### Wie diese Werkzeuge gebaut sind

- **Keine Anmeldung, kein Konto.** Nichts, was eine Klasse vor der ersten Aufgabe ausbremst.
- **Kein Server.** Alle Eingaben bleiben im Browser der Nutzerin oder des Nutzers. Es gibt kein Tracking und keine Analyse-Werkzeuge.
- **Offline nutzbar.** Die meisten Tools lassen sich als App auf dem Gerät ablegen und funktionieren ohne Netz — praktisch im Schulhaus wie auf Station.
- **Offen lizenziert.** Quelltext unter MIT, didaktische Inhalte unter CC BY-SA 4.0. Nutzen, anpassen und weitergeben ist ausdrücklich erwünscht.

## reveal.js plugins

Small, dependency-free plugins for [reveal.js](https://revealjs.com), built for teaching at a smartboard. Each one ships its own CSS, works with a finger on a touch display, and is available on npm. Live demos are linked from each repository.

| Plugin | What it does |
|---|---|
| **[quiz](https://github.com/FlorianLoyns/reveal.js-quiz)** | Interactive exercises: single choice, multiple choice, true/false, ordering and matching |
| **[quizgrid](https://github.com/FlorianLoyns/reveal.js-quizgrid)** | A category × points quiz board — tap a tile to reveal the question, then the answer |
| **[glossary](https://github.com/FlorianLoyns/reveal.js-glossary)** | Inline term definitions: mark a term, hover or tap it, get a short explanation next to it |
| **[termcluster](https://github.com/FlorianLoyns/reveal.js-termcluster)** | Interactive word clouds, ideal as an advance organizer at the start of a topic |
| **[sequence](https://github.com/FlorianLoyns/reveal.js-sequence)** | Walk a procedure step by step, or a course of events along a real time axis |
| **[stepped](https://github.com/FlorianLoyns/reveal.js-stepped)** | Build long quotes and source texts sentence by sentence, so the audience reads along |
| **[touchcontrols](https://github.com/FlorianLoyns/reveal.js-touchcontrols)** | On-screen controls for touch displays and smartboards, including annotation |
